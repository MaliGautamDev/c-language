1. Name 5 IT job roles and write one line about what each role does.

Software Developer – Develops, maintains, and improves software applications by writing and managing code.

Software Tester – Tests software applications to find bugs and ensure that they work correctly.

UI/UX Designer – Designs the user interface and improves the overall user experience of an application.

Data Analyst – Analyzes data to find useful information and helps businesses make better decisions.

AI Engineer – Develops AI-based systems and solutions using artificial intelligence and machine learning technologies.
