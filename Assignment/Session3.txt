1. Write the full form and one-line use of HTTP, HTTPS, FTP, SMTP.

  1.HTTP – HyperText Transfer Protocol
    -It is used to transfer data between a web browser and a web server.

  2.HTTPS – HyperText Transfer Protocol Secure
    -It is used to securely transfer data between a browser and a web server.

  3.FTP – File Transfer Protocol
    -It is used to transfer files between computers over a network.

  4.SMTP – Simple Mail Transfer Protocol
    -It is used to send emails from one mail server to another.



2. What is the difference between IPv4 and IPv6? Answer in 2 lines.

  1.IPv4
    -uses a 32-bit address, for example 192.168.1.1, and has a limited number of addresses.

  2.IPv6
    -uses a 128-bit address, so it provides a much larger number of IP addresses.

4. What do these HTTP status codes mean: 200, 301, 404, 500, 403?

   1.200(OK)
     -The request was successful.

   2.301(Moved Permanently)
     -The requested page has been permanently moved to another URL.

   3.404(Not Found)
     -The requested page or resource could not be found.

   4.500(Internal Server Error)
     -There is an error on the server while processing the request.

   5.403(Forbidden)
     -The server understood the request but does not allow access.


5. Explain DNS hierarchy (root, TLD, domain, subdomain) with www.google.com as an example.

  For www.google.com:

      1.Root (.)
         – The top level of the DNS hierarchy.

      2.TLD (.com)
         - The top-level domain.

      3.Domain (google)
         - The main domain name.

      4.Subdomain (www)
         - A subdomain used under the google.com domain.
