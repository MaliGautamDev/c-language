1. Write the Git command for each: initialize a repo, stage all files, commit with a message, push to remote, pull latest changes.


   1.Initialize a repository:
      - git init

   2.Stage all files:
      - git add 

   3.Commit with a message:
      - git commit -m "Initial commit"

   4.Push to remote repository:
      - git push origin main

   5.Pull the latest changes:
      - git pull origin main


2.What is the difference between git fetch and git pull? Answer in 2 lines.

 
   1.git fetch 
      -downloads the latest changes from the remote repository but does not apply them to your current branch.

   2.git pull 
      -downloads the changes and also updates your current branch with those changes.

4. What is the difference between a Fork and a Pull Request? Answer in 2 lines.

    1.Fork
       - creates a copy of someone else's repository in your own GitHub account.

    2.Pull Request
       - is used to propose your changes to the original repository so the owner can review and merge them.
